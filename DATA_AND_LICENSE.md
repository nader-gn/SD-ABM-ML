# Data and license

The repository contains the harmonized model inputs, derived tables, configuration files, and computational artifacts required by the reproduction workflow. Source datasets are documented in the manuscript and remain subject to the terms and attribution requirements of their original providers.

No additional reuse rights for upstream data are granted by this repository. The included reproduction workflow operates on the harmonized or derived inputs provided here and does not require private upstream data archives.

If a software license is added to the repository, it should apply only to materials for which the repository maintainers hold the relevant rights and should not override third-party data terms.
